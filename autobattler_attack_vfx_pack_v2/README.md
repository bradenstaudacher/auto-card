# Autobattler Attack VFX Pack v2

Transparent 64x64 attack overlays for five class types:

- Occult / purple: void sigil bolt
- Holy / light yellow: radiant spear
- Law / light blue: geometric verdict beam
- Fury / crimson: claw swipe
- Death / black: smoky scythe sweep

Each class includes:

- Four individual transparent PNG frames
- A 4x1 transparent spritesheet, 256x64
- Preview frames rendered on top of a unit circle
- An animated preview GIF

The production overlay assets are transparent and should be rendered above your existing unit circles.

Default direction is east / left-to-right. Rotate the wrapper toward the target.

Recommended animation duration: 360ms using `steps(4)`.
